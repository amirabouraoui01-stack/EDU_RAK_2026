# Empreintes locales du projet final

La table fp-lib-table associe les empreintes au projet KiCad VeillePorte.

- LBOOST1 utilise LPS4018-223MRC:IND_LPS4018-223MRC ; le modèle 3D correspondant est dans 3dmodels/.
- AE1 utilise VeillePorte_Antennes:IFA_868_CST_30x20_PisteFine ; la géométrie suit le modèle CST retenu. Voir ../../docs/EMPREINTE_ANTENNE.md.

Ouvrir VeillePorte/veilleporte_complet.kicad_pro pour charger les tables locales. Le PCB reste à créer ; le DRC sera nécessaire après placement et routage.
