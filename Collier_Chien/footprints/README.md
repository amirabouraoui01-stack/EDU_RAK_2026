# Empreinte LBOOST1

La bibliothèque locale `LPS4018-223MRC.pretty` contient `IND_LPS4018-223MRC.kicad_mod` et est enregistrée dans `../fp-lib-table` sous le nom **LPS4018-223MRC**. Elle résout la référence existante du schéma : `LPS4018-223MRC:IND_LPS4018-223MRC`.

L’empreinte et son modèle 3D ont été importés du [dépôt SmartPot_RAK3172](https://github.com/MaxBarbe/SmartPot_RAK3172/tree/main/pot_fleur/footprints/LPS4018-223MRC.pretty), déjà téléchargé. Le modèle utilise le chemin portable `${KIPRJMOD}/3dmodels/LPS4018-223MRC.step`. La feuille BQ25570 reste inchangée.

La référence fabricant est **Coilcraft LPS4018-223MRC**, inductance 22 µH. [Documentation fabricant](https://www.coilcraft.com/en-us/products/power/shielded-inductors/ferrite-drum/lps/lps4018/).

Si le projet est déjà ouvert, fermer puis rouvrir le projet `collier_chien.kicad_pro` pour recharger la table locale, puis relancer « Mettre à jour le PCB à partir du schéma ». Utiliser ce projet complet : ouvrir seulement un schéma copié ailleurs ne charge pas sa bibliothèque locale.
